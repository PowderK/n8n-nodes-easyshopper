# EASY Shopper Home Assistant Integration

Diese Integration ermöglicht es, die EASY Shopper Einkaufsliste direkt in Home Assistant zu verwalten.

## Funktionen
- **Automatische Synchronisation**: Die Einkaufsliste wird regelmäßig mit der EASY Shopper Cloud abgeglichen.
- **To-Do Liste**: Füge Artikel in Home Assistant hinzu oder hake sie ab.
- **Automatisches Löschen**: Wenn ein Artikel in HA als "erledigt" markiert wird, wird er automatisch aus der EASY Shopper Liste gelöscht.
- **Pairing-QR-Code**: Zeigt einen QR-Code als Bild-Entität an, um dein Smartphone einfach mit dem Home Assistant Account zu verbinden.
- **Einfaches Setup**: Suche deinen Markt bequem per Postleitzahl.

## Installation
1. Kopiere den Ordner `custom_components/easyshopper` in dein `custom_components` Verzeichnis von Home Assistant.
2. Starte Home Assistant neu.
3. Gehe zu **Einstellungen > Geräte & Dienste > Integration hinzufügen**.
4. Suche nach **EASY Shopper** und folge den Anweisungen.

## Rechtliche Hinweise
Dieses Projekt steht in keiner Verbindung zur EDEKA-Gruppe oder Whiz-Cart. Die Nutzung erfolgt auf eigene Gefahr.
